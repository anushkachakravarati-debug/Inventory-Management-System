Inventory Management System

A Python-based Inventory Management System built using Object-Oriented Programming (OOP). It helps manage products, track stock, and calculate total inventory value through a menu-driven command-line interface.

Features

- Add new products
- View all products
- Search products by product ID
- Update product details
- Delete products
- Update stock quantities
- Check low-stock products
- Calculate total inventory value
- Save product data to a text file
- Load previously saved product data

Technologies Used

- Python 3
- Object-Oriented Programming (OOP)
- File Handling
- Command-Line Interface (CLI)

Product Details

Each product contains:

- Product ID
- Name
- Category
- Price
- Quantity

How to Run

1. Install Python 3.

2. Download or clone this repository.

3. Open the project folder in your terminal.

4. Run the Python file:
   
   python "Inventory Management System.py"

Data Storage

Product information is stored in "products.txt" using file handling. Use the Save To File and Load From File options to save and retrieve product records.
